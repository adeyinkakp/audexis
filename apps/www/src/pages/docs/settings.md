# Settings

Open Settings from the sidebar or app menu. **Ctrl+,** on Windows and **Cmd+,**
on macOS also open it. Feature-specific buttons open the relevant section
directly.

## Appearance

Choose a light, dark, or system theme. System follows the operating system’s
appearance preference.

Row density controls how tightly rows are arranged: Compact, Default, or
Comfortable. Reduced motion limits supported interface animations. These choices
apply when you choose **Save changes**.

## Library

Add or remove watched music folders, then save. The app checks that the selected
folders are available.

Use Rescan to refresh the saved library roots. The rescan action is unavailable
while folder edits need to be saved. Removing a root affects library records and
playlists, but does not erase the source audio files.

[Library and folders](/docs/library) explains disconnected drives, overlapping
roots, and missing-file recovery.

## Metadata

Search the regular metadata field catalog and select the fields that should
appear in **Track Info → Details**. Selections save automatically.

These are editor-layout preferences. Hiding Artist, for example, does not remove
the artist tag from any song. To delete a value, edit that song’s metadata and
save the deletion.

Unsupported binary frame types are not offered as ordinary text inputs. Artwork
has its own editor.

## Custom Fields

Create reusable definitions containing a display title, native key, and Text or
URL type. Choose **Save Fields** to store them.

These definitions are available in the custom-field editor and Songs column
menu. Creating a definition does not populate songs with values. Removing one
does not delete existing embedded tags.

See [Custom fields](/docs/custom-fields) for examples and key validation.

## Logs

Use this section or **Help → View Logs…** to inspect recorded backend errors.
Logs can help explain failed metadata saves, scan problems, or playback errors.

When reporting a problem, include the relevant error and the steps that caused
it. Review log text before sharing because paths and diagnostic details may
identify files on your computer.
