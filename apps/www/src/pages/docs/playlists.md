# Playlists and favorites

## Create a playlist

Open Playlists and use its create action, or choose **File → New Playlist…**.
Give the playlist a name you can recognize later.

A playlist stores references to library tracks. It does not make extra copies of
the audio files or create a folder on disk.

## Add songs

Right-click a song and choose **Add to Playlist**, then select a playlist. If
the menu says no playlists are available, create one first.

The same song can belong to different playlists. Its metadata and artwork still
come from the same underlying file, so a saved tag edit is visible wherever that
file appears.

## Arrange and maintain a playlist

Open a playlist to see its tracks. Use the available reorder handles to change
the saved sequence. Rename it when its purpose changes.

**Remove from Playlist** removes that playlist entry. Deleting a playlist
removes the saved collection. Neither operation deletes the referenced audio
files.

Playlist order and playback order are separate concepts. Shuffle changes the
active playback order; it does not permanently shuffle the saved playlist.

## Favorites

Use a song’s heart control or the **Heart** context-menu item to toggle its
favorite status. Open Favorites to browse the tracks you have marked.

Favorite status is stored in Audexis’s library database. It is not automatically
written as a rating or favorite tag into the audio file, and other music players
will not necessarily see it.

## Missing sources

Playlists depend on library file records. A disconnected drive or moved file can
make a referenced track unavailable. Try reconnecting the drive or relinking the
missing file before removing its record.

Removing a watched library folder can also remove songs from playlists. Keep a
[backup of your library data](/docs/privacy-and-data) if those collections are
important to you.
