# Security policy

Audexis processes local media files and library data, and includes optional
network services, authentication, and cloud storage. Please report suspected
vulnerabilities privately so they can be investigated before details are public.

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 0.10.x  | :white_check_mark: |
| < 0.10  | :x:                |

## Reporting a vulnerability

On the [repository Security page](https://github.com/adeyinkakp/audexis/security),
use **Report a vulnerability**.

Do not submit a public pull request containing an undisclosed exploit or
vulnerability details before coordinating privately with the maintainer.

## What to include

- Affected app, crate, service, version.
- A description of the vulnerability and its likely impact.
- Reproduction steps or a minimal proof of concept.
- Required configuration, privileges, and platform details.
- A proposed fix, if you have one.
