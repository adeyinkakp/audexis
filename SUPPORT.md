# Support

Audexis is under active development.

## Start here

Read the [README](README.md) for the project overview and links to each
app and crate. For setup and build questions, use the README for the crate/app
you are working with. See [Contributing](CONTRIBUTING.md) for development checks.

The repository includes website documentation under `apps/www/src/pages/docs`.
Pages still describe the previous tauri implementation, so use the current
component READMEs for build commands and repository paths.

## Questions and troubleshooting

Search [existing issues](https://github.com/adeyinkakp/audexis/issues) for your
symptoms or error message. If nothing matches, open an issue with a clear title
and explain what you were trying to do.

For a useful report, include:

- App or crate, and version or commit.
- Operating system and version; device or simulator.
- Whether you are using local files, a self-hosted server, or cloud services.
- REproduction steps, expected behavior, and actual behavior.
- Relevant error messages, logs, and or screenshots.
- File container and codec for playback or metadta problems, if known.

For build failures, include the command, working directory, tool versions, and
the relevant error output. For server problems, include configuration names
and non-sensitive settings needed to reproduce the issue.

Before sharing logs or screenshots, remove credentials, tokens, signed URLs,
personal information, and private file paths. Do not upload your full library
or copyrighted audio; use a minimal sample you have permission to share.

## Feature requests

Open an issue describing the problem you want to solve and an example of the
workflow you want.
